Instalación rápida en XAMPP:
1. Copiar la carpeta sistema_envios_figma dentro de htdocs.
2. Renombrarla a sistema_envios si deseas usar la ruta estándar.
3. Importar sql/database.sql en phpMyAdmin o MySQL Workbench.
4. Revisar config/conexion.php y ajustar usuario/contraseña de MySQL si aplica.
5. Abrir http://localhost/sistema_envios/login.php

Características incluidas:
- Login con AJAX.
- Dashboard responsive con Bootstrap.
- Crear solicitud de envío.
- Generación automática de código guía.
- Historial de envíos.
- Detalle del envío.
- Actualización de estado.
- Tracking público con AJAX cada 3 segundos.
- Barra de progreso por estado.
- Diseño institucional inspirado en un portal bancario / prototipo de Figma.
